## Axiom

**Composable. Container-driven. One primitive. Every surface.**

GALAXY is the visual primitive that renders the governance universe. It fills its container. It adapts to its surface. Web, iOS, Android — same data, native rendering.

---

## Architecture

```
magic scan → build-scopes-json → scopes.json → GALAXY.init(container, options)
```

GALAXY reads `scopes.json`. The container determines the size. Options determine what's shown. No modes. Configuration only.

---

## Data Layer

`scopes.json` is the shared data layer across all surfaces:

```json
{
  "id": "SCOPE_NAME",
  "label": "Display Name",
  "bits": 127,
  "size": 60,
  "color": "#00ff88",
  "category": "RUNTIME",
  "repo": "org-name",
  "inherits": "PARENT_SCOPE"
}
```

Generated by `build-scopes-json` from `magic scan` across all governance repos. One file. Every surface reads it.

## Initialization

```
GALAXY.init(container, options)
```

| Option | Type | Default | Purpose |
|--------|------|---------|---------|
| `height` | string | container height | CSS height for the graph |
| `hud` | boolean | false | Compliance ring + scope count |
| `search` | boolean | false | Search bar with filter + focus |
| `detail` | boolean | false | Right-side detail panel |
| `dock` | boolean | false | Bottom-center fleet launchers |

Container is the only variable. Galaxy fills it.

```
{ height: '70vh', hud: true, search: true, dock: true }  → hero embed
{ height: '100vh', hud: true, search: true, detail: true, dock: true }  → standalone
{ height: '300px', hud: true }  → widget
```

## Graph

Nodes are scopes. Edges are `inherits` chains.

### Nodes

```
size   = tier threshold (255→80, 127→60, 63→40, 35→30, 0→20)
color  = category (8 colors from DESIGN.md)
label  = scope name
shape  = dot
border = 2px, highlight → white 3px
font   = system font, size scales with node (min 11)
```

### Edges

```
from   = inherits (parent)
to     = scope (child)
color  = rgba(255,255,255,0.08), highlight → 0.3
width  = 1
smooth = continuous
arrows = none
```

## Interactions

| Action | Behavior |
|--------|----------|
| Click node | Show detail panel |
| Double-click node | Zoom to 2x |
| ESC | Close detail, fit graph |
| Search input | Filter nodes by label/category, focus single match |
| Click inheritor | Navigate to that scope |

## Overlays

### HUD (top-left)

SVG compliance ring: 3 concentric arcs at different opacities. Average bits across all scopes. Scope count below.

### Search (top-center)

Glass morphism input. Expands on focus. Filters graph on input. ESC clears.

### Detail Panel (right)

340px panel, slides in on node click. Contains:
- Scope name
- Compliance ring (140px)
- Tier badge (name + color)
- Category, repo, bits, inherits
- Inheritors grid (2-column, color-coded, clickable)

### Dock (bottom-center)

Glass morphism bar. Fleet site launchers + TALK.

## Responsive

Galaxy reads container dimensions. Adapts:
- Small container → smaller nodes, fewer labels
- Mobile → detail panel slides up from bottom
- Search and HUD scale with container

Not "modes." Container-driven.
