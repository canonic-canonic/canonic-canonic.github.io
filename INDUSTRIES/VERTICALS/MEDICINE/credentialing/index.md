All credentials MUST be verified from primary sources. Self-attestation is insufficient.

```
Primary Sources:
- Medical license: State medical board
- DEA: DEA CSOS
- NPI: NPPES registry
- Board certification: ABMS/AOA
- Education: Medical school, residency
- Malpractice: NPDB, state records
```

### 2. Continuous Monitoring

Credentials MUST be monitored continuously, not just at enrollment.

```
Monitoring frequency:
- License status: Monthly
- Sanctions: Monthly (OIG, SAM, state)
- Board actions: Monthly
- Malpractice claims: Quarterly
```

### 3. Jurisdictional Compliance

Provider privileges MUST match jurisdictional requirements.

```
Requirements by jurisdiction:
- State: Medical license, controlled substance
- Federal: DEA, Medicare enrollment
- Payer: Network participation
- Facility: Medical staff privileges
```

### 4. Expiration Management

All time-bound credentials MUST be tracked with renewal workflows.

```
Tracked expirations:
- Medical license (1-3 years)
- DEA registration (3 years)
- Board certification (10 years)
- CME requirements (per state)
- Malpractice insurance (annual)
```
