## Axioms

### 1. mCODE Conformance

All oncology data MUST conform to mCODE (minimal Common Oncology Data Elements).

```
Required mCODE profiles:
- CancerPatient
- PrimaryCancerCondition
- TNMStageGroup
- CancerRelatedProcedure
- CancerRelatedMedicationStatement
- TumorMarker
- GenomicsReport
- CancerDiseaseStatus
```

### 2. Staging Integrity

Cancer staging MUST use standardized systems (AJCC TNM) and be documented at diagnosis and restaging events.

### 3. Treatment Protocol Binding

Treatment recommendations MUST reference NCCN guidelines or institutional protocols with version numbers.

### 4. Tumor Board Documentation

Multidisciplinary tumor board discussions MUST be documented with attendees, recommendations, and rationale.

### 5. Outcomes Tracking

Patient outcomes (response, progression, survival) MUST be tracked using RECIST or disease-specific criteria.
